# RouteInformationProvider 与 PlatformRouteInformationProvider 详解

## 概述

`RouteInformationProvider` 和 `PlatformRouteInformationProvider` 是 Flutter 路由系统中负责管理路由信息的核心组件。它们作为 `Router` 和平台之间的桥梁，处理路由信息的双向流动：从平台接收路由变更通知，以及将路由变更报告回平台（特别是在 Web 应用中）。

## RouteInformationProvider 抽象类

`RouteInformationProvider` 是一个抽象类，继承自 `ValueListenable<RouteInformation>`，为路由信息提供者定义了基本接口。

### 类定义

```dart 1446:1491:packages/flutter/lib/src/widgets/router.dart
abstract class RouteInformationProvider extends ValueListenable<RouteInformation> {
  /// A callback called when the [Router] widget reports new route information
  ///
  /// The subclasses can override this method to update theirs values or trigger
  /// other side effects. For example, the [PlatformRouteInformationProvider]
  /// overrides this method to report the route information back to the engine.
  ///
  /// The `routeInformation` is the new route information generated by the
  /// Router rebuild, and it can be the same or different from the
  /// [value].
  ///
  /// The `type` denotes the [Router]'s intention when it reports this
  /// `routeInformation`. It is useful when deciding how to update the internal
  /// state of [RouteInformationProvider] subclass with the `routeInformation`.
  /// For example, [PlatformRouteInformationProvider] uses this property to
  /// decide whether to push or replace the browser history entry with the new
  /// `routeInformation`.
  ///
  /// For more information on how [Router] determines a navigation event, see
  /// the "URL updates for web applications" section in the [Router]
  /// documentation.
  void routerReportsNewRouteInformation(
    RouteInformation routeInformation, {
    RouteInformationReportingType type = RouteInformationReportingType.none,
  }) {}
}
```

### 核心职责

1. **提供路由信息**：通过 `value` getter（继承自 `ValueListenable`）向 `Router` 提供当前的路由信息
2. **通知监听者**：当路由信息发生变化时，通知监听者（通常是 `Router` widget）
3. **处理路由报告**：当 `Router` 报告新的路由信息时，通过 `routerReportsNewRouteInformation` 方法处理

### routerReportsNewRouteInformation 方法

这是 `RouteInformationProvider` 的核心方法，当 `Router` 需要报告新的路由信息时会被调用。

**参数说明**：

- `routeInformation`：由 `Router` 重建生成的新路由信息，可能与当前的 `value` 相同或不同
- `type`：`Router` 报告此路由信息的意图类型，用于决定如何处理路由信息更新

**类型说明**：

`RouteInformationReportingType` 枚举有三种值：

- `none`：默认值，表示 `Router` 没有特定意图，只是检测到路由信息可能因重建而改变
- `neglect`：表示路由信息是在 `Router.neglect` 调用期间生成的
- `navigate`：表示路由信息是在 `Router.navigate` 调用期间生成的

子类可以重写此方法来实现特定的行为，例如 `PlatformRouteInformationProvider` 会重写此方法以将路由信息报告回引擎。

## PlatformRouteInformationProvider 类

`PlatformRouteInformationProvider` 是 `RouteInformationProvider` 的具体实现，专门用于处理平台级别的路由信息变更。

### 类定义


### 混入的 Mixin

- `WidgetsBindingObserver`：用于监听平台级别的路由推送事件（如 `didPushRouteInformation`）
- `ChangeNotifier`：用于通知监听者路由信息的变化

### 核心方法详解

#### routerReportsNewRouteInformation

这是 `PlatformRouteInformationProvider` 最重要的方法，重写了父类的空实现：

```dart 1522:1539:packages/flutter/lib/src/widgets/router.dart
  @override
  void routerReportsNewRouteInformation(
    RouteInformation routeInformation, {
    RouteInformationReportingType type = RouteInformationReportingType.none,
  }) {
    SystemNavigator.selectMultiEntryHistory();
    SystemNavigator.routeInformationUpdated(
      uri: routeInformation.uri,
      state: routeInformation.state,
      replace: switch (type) {
        RouteInformationReportingType.neglect => true,
        RouteInformationReportingType.navigate => false,
        RouteInformationReportingType.none => _equals(_valueInEngine.uri, routeInformation.uri),
      },
    );
    _value = routeInformation;
    _valueInEngine = routeInformation;
  }
```

**执行流程**：

1. **选择多入口历史模式**：调用 `SystemNavigator.selectMultiEntryHistory()`，这会覆盖 `Navigator.reportsRouteUpdateToEngine` 的初始化行为
2. **更新路由信息到引擎**：调用 `SystemNavigator.routeInformationUpdated` 将路由信息报告回引擎
3. **更新内部状态**：更新 `_value` 和 `_valueInEngine`

**replace 参数的决定逻辑**：

- `neglect`：`replace = true`，替换当前历史条目而不创建新条目
- `navigate`：`replace = false`，创建新的历史条目
- `none`：根据 URI 是否与引擎中的 URI 相同来决定，如果相同则替换，否则创建新条目

#### _platformReportsNewRouteInformation

```dart 1549:1556:packages/flutter/lib/src/widgets/router.dart
  void _platformReportsNewRouteInformation(RouteInformation routeInformation) {
    if (_value == routeInformation) {
      return;
    }
    _value = routeInformation;
    _valueInEngine = routeInformation;
    notifyListeners();
  }
```

当平台报告新的路由信息时（例如用户点击浏览器后退按钮），此方法会被调用。它会：

1. 检查路由信息是否与当前值相同，如果相同则直接返回
2. 更新内部状态
3. 通知所有监听者

## 工作流程

### 路由信息流向

1. **平台 → Router**：
   - 平台推送路由信息（如浏览器 URL 变更）
   - `PlatformRouteInformationProvider.didPushRouteInformation` 被调用
   - 更新 `_value` 并通知监听者
   - `Router` 接收到通知，解析路由信息并导航

2. **Router → 平台**：
   - `Router` 检测到路由配置变化
   - 调用 `RouteInformationProvider.routerReportsNewRouteInformation`
   - `PlatformRouteInformationProvider` 重写此方法，通过 `SystemNavigator.routeInformationUpdated` 报告回引擎
   - 平台更新 URL（在 Web 应用中更新浏览器地址栏）

### 使用场景

1. **Web 应用**：保持浏览器 URL 与 Flutter 路由状态同步
2. **状态恢复**：在应用被杀死前保存路由信息，恢复时重新加载
3. **深度链接**：处理来自外部的路由请求（如点击通知打开特定页面）

## 关键设计点

1. **双向通信**：既可以从平台接收路由信息，也可以向平台报告路由信息
2. **历史管理**：通过 `replace` 参数控制是否创建新的浏览器历史条目
3. **观察者模式**：使用 `ValueListenable` 和 `ChangeNotifier` 实现监听者模式
4. **平台集成**：通过 `WidgetsBindingObserver` 与平台生命周期集成

## 相关类型

- `RouteInformation`：路由信息的数据类，包含 URI 和状态
- `RouteInformationReportingType`：路由报告类型枚举
- `Router`：使用 `RouteInformationProvider` 的路由组件
- `SystemNavigator`：系统导航器，用于与引擎通信
